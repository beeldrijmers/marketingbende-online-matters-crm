# Gearchiveerde ontwikkelaarsdocumentatie

De inhoud onder `doc/src/content/docs` is afkomstig uit het oorspronkelijke
Atomic CRM-project en blijft alleen als technische naslag beschikbaar.

Deze map wordt niet gebouwd of gepubliceerd. De actieve CRM-deploy gebruikt
uitsluitend het hoofdproject en publiceert de inhoud van `dist` naar de
`gh-pages`-branch. Daarom bevat deze archiefmap bewust geen eigen
`package.json` of lockfile meer.

Wanneer een document nog relevant is voor de huidige CRM, controleer de inhoud
eerst tegen de actuele implementatie voordat je erop vertrouwt.
